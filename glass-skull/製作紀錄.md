# 霧面玻璃骷髏：製作紀錄

本檔記錄這個 3D 玻璃骷髏用到的程式語言、建立流程，以及玻璃材質的原理和參數，方便日後修改或重建。

- 線上版本：https://claude.ai/artifact/Ui6eUYFx8GirrZjt4t8bmR
- 原始碼位置：`glass-skull/`（分支 `claude/brave-davinci-tzeb4k`）

---

## 1. 使用的程式語言

| 語言 | 用在哪裡 | 負責什麼 |
|---|---|---|
| **JavaScript（ES Modules）** | `src/template.html` 的 `<script type="module">` | 場景、相機、滑鼠旋轉縮放、動畫迴圈、控制面板、讀取 .glb、畫背景 |
| **Three.js 0.170.0** | 透過 import map 從 jsDelivr 載入 | WebGL 3D 引擎：場景、網格、算圖目標、後製管線 |
| **GLSL**（WebGL 2 / GLSL ES 3.0） | `ShaderMaterial` 和 `ShaderPass` 裡的字串 | 在顯示卡上計算玻璃：折射、色散、反射、吸收、霧面、顆粒 |
| **HTML / CSS** | `src/template.html` 上半部 | 標題、控制面板、手機版排版 |
| **Canvas 2D API** | `drawBackdrop()` | 畫背景板：灰底、格線、哥德體大字母 |
| **Python 3 + NumPy** | `assets/convert_skull.py`、`build.py` | 建置用：處理模型、把資料嵌入網頁（不在瀏覽器執行） |
| **Python（Blender bpy）** | `frosted_glass_material.py` | 在 Blender 建立同款玻璃材質和攝影棚 |

### 重建步驟

```bash
# 1. 下載原始模型（CC BY 4.0）
curl -L -o skull.babylon https://raw.githubusercontent.com/BabylonJS/Assets/master/meshes/skull.babylon

# 2. 轉檔：焊接接縫、平滑、壓縮（第三個參數是平滑次數，預設 20）
```

## 2. 模型建立流程

### 2.1 模型來源

- 來源：Babylon.js Assets 的 `meshes/skull.babylon`
- 授權：**CC BY 4.0**，使用時必須標註出處（網頁左下角和「Model」面板已標註）
- 原始資料：41,864 個頂點、74,998 個三角面

### 2.2 轉檔處理（`convert_skull.py`）

| 步驟 | 做法 | 原因 |
|---|---|---|
| 1. 座標轉換 | z 軸取負號 | Babylon 用左手座標系，Three.js 用右手座標系。鏡像後三角面的方向剛好也正確，所以不再翻轉頂點順序 |
| 2. 焊接接縫 | 位置相同（四捨五入到小數 5 位）的頂點合併成一個，並移除退化的三角面 | 原始模型在貼圖接縫處把頂點存成兩份，共 10,966 條沒接起來的邊。不先合併，平滑時接縫會被拉開，產生破口。合併後剩 37,499 個頂點，開口邊數為 0 |
| 3. Taubin 平滑 | 20 次，每次先 λ = 0.5 收縮，再 μ = −0.53 膨脹 | 去掉掃描的凹凸，同時保持體積不縮水 |
| 4. 重算法線 | 以三角面面積加權平均 | 平滑後的表面光影才正確 |
| 5. 壓縮 | 位置存成 int16，法線存成 int8，索引存成 uint16 | 檔案約 787 KB，用 base64 嵌進 HTML |

`skull.bin` 的二進位格式（little endian）：

```
uint32 頂點數, uint32 三角面數, float32 保留欄位
int16  位置[頂點數 × 3]   ÷ 32767 → 範圍 [-1, 1]
int8   法線[頂點數 × 3]   ÷ 127，補齊到 2 bytes
uint16 索引[三角面數 × 3]
```

### 2.3 在網頁中解碼（JavaScript）

```js
const bin = Uint8Array.from(atob(base64Text), (c) => c.charCodeAt(0));
const dv = new DataView(bin.buffer);
const vc = dv.getUint32(0, true), tc = dv.getUint32(4, true);
// 讀出 int16 位置、int8 法線、uint16 索引 → 建立 THREE.BufferGeometry
```

## 3. 算圖流程

每一格畫面（`renderer.setAnimationLoop`）依序執行：

```
1. controls.update()          更新相機（拖曳、縮放、自動旋轉）
2. 背面 pass                  只畫模型背面 → backRT（存每個像素的出口法線和深度）
3. 主 pass（EffectComposer）
   ├─ RenderPass              背景板 + 玻璃骷髏（玻璃著色器讀取 backRT）
   ├─ OutputPass              Neutral 色調映射 + 轉 sRGB
   └─ ShaderPass（lensPass）  鏡頭色邊 + 底片顆粒
```

- **圖層分工：** 背面網格放在 layer 1，相機切到 layer 1 時只會畫它；主畫面用 layer 0。
- **背景板：** 背景板是相機的子物件，固定在相機前方 z = −6.6，所以不論怎麼轉，背景都在骷髏後面約 2 個單位處。
- **反鋸齒：** 主算圖目標使用 2× MSAA 多重取樣。
- **背面 pass：** 用一半解析度算圖，只存法線和深度，不影響畫質。

---

## 3.1 效能優化（流暢度）

| 做法 | 說明 |
|---|---|
| 按需算圖 | 畫面沒有變化時（沒拖曳、沒自動旋轉、沒調滑桿）不重畫，GPU 閒置，網頁不卡。使用 `preserveDrawingBuffer: true` 保留最後一格畫面 |
| 移動時降取樣 | 拖曳或自動旋轉時，霧面取樣從 8 次降到 3 次。放開 0.18 秒後重畫一格 8 次取樣的高畫質畫面 |
| 自動調整解析度 | 移動時每 0.7 秒檢查平均每格時間：超過 24 ms 就把解析度降到 80%（最低 50%），低於 13 ms 就慢慢升回來。靜止畫面一律用全解析度 |
| 像素比上限 | 最高 1.5 倍（原本 2 倍），4K / Retina 螢幕的像素數少了將近一半 |
| 厚度搜尋只做一次 | 原本每個霧面取樣都重新搜尋背面（8 × 24 次貼圖讀取），現在每個像素只搜尋一次（約 24 次） |
| 背面 pass 半解析度 | 背面深度只需要粗略位置，用一半解析度就夠 |
| MSAA 4× → 2× | 減少多重取樣的頻寬 |

在無頭瀏覽器的軟體算圖中測量，旋轉時每格時間從 6.2 秒降到 1.8 秒，約快 3.5 倍。實際裝置用的是 GPU，絕對速度會快很多，但比例相近。

## 4. 玻璃材質原理（GLSL 著色器）

這個玻璃不是貼圖，也沒用 Three.js 內建的透光材質。每個像素都由自訂著色器追蹤一條光線穿過玻璃。

### 4.1 背面 pass

```glsl
// 輸出：rgb = 視角空間的外向法線，a = 深度（距相機的距離）
gl_FragColor = vec4(normalize(vN), -vP.z);
```

存在一張 HalfFloat 格式的算圖目標裡，供下一步查出光線從哪裡離開玻璃。

### 4.2 玻璃著色器的計算步驟

| # | 物理現象 | 實作方式 |
|---|---|---|
| 1 | **霧面（噴砂表面）** | 靜止時每像素取樣 8 次，移動時 3 次。每次把表面法線在一個錐角內隨機傾斜（`microNormal`），錐角 = 粗糙度² × 0.9 |
| 2 | **表面反射** | Schlick Fresnel：`F = F0 + (1 − F0)(1 − cosθ)^5`，其中 `F0 = ((n − 1)/(n + 1))²`。反射用比透射更銳利的法線，模擬拋光表層 |
| 3 | **薄膜虹彩** | 膜厚 380 nm、膜折射率 1.38，分別用 650 / 530 / 450 nm 計算干涉：`R = 0.5 + 0.5·cos(4π·n·d·cosθ / λ)` |
| 4 | **進入玻璃的折射** | `refract(V, n1, 1.0 / ior)`（Snell 定律） |
| 5 | **穿過真實厚度** | 每個像素只做一次：沿平滑法線的折射方向走 18 步，比對背面深度，找到出口，再用 4 次二分法精修。霧面的各個取樣共用這個出口。出口和入口的距離就是玻璃內的路徑長度 |
| 6 | **離開玻璃的折射＋色散** | 紅、綠、藍各用不同折射率再折射一次，由 Abbe 數 V 推出：Δ = (n − 1) / V，n_R = n − 0.3Δ、n_G = n、n_B = n + 0.7Δ |
| 7 | **全內反射** | 超過臨界角時 `refract()` 回傳 0，改成反射，取環境光（× 0.85） |
| 8 | **背景交點** | 出射光線和背景平面 z = −6.6 精確求交，換算成背景貼圖的 UV |
| 9 | **霧面模糊隨距離增加** | 依「出口到背景的距離 × 散射角」計算模糊半徑，換算成 mipmap 層級，再用 `textureLod` 取樣 |
| 10 | **吸收（Beer–Lambert）** | `color *= exp(−σ × 路徑長度)`，σ 偏綠，所以厚的地方會帶一點淡紫 |
| 11 | **內部散射（乳白感）** | `mix(color, 環境散射光, 1 − exp(−散射係數 × 路徑長度 × 2))` |
| 12 | **能量合成** | `反射 × F + 透射 × (1 − F)`，最後平均所有樣本 |

### 4.3 程式繪製的攝影棚環境光（世界座標固定）

| 光源 | 方向 | 顏色／強度 |
|---|---|---|
| 背景環境 | 下方到上方漸層 | 灰白 (0.66 → 0.90) |
| 主光柔光箱 | 左上前方 (−0.6, 0.7, 0.45) | 白色 × 2.4 |
| 紫色輪廓光 | 右後方 (0.45, 0.35, −0.8) | 紫 (0.55, 0.42, 1.0) |
| 冷色補光 | 右側 (0.95, −0.15, 0.3) | 淡藍 × 0.7 |

### 4.4 後製（lensPass）

- **鏡頭色邊：** 紅、藍通道沿徑向反方向偏移，越靠畫面邊緣偏移越多。
- **底片顆粒：** 兩層雜湊雜訊，暗部較強，`uTime` 讓每格的顆粒都不同。

### 4.5 已知的近似

- 只找第一個出口。光線出去後再穿進骷髏其他部位，例如穿過眼窩後再進入骨頭，不會繼續追蹤。
- 環境光是程式畫的，不是 HDR 環境貼圖。
- 背景只有一張平面。

## 5. 材質參數表

### 5.1 網頁版（控制面板）

| 面板名稱 | 對應 uniform | 範圍 | 預設值 | 物理意義 |
|---|---|---|---|---|
| Frost (surface roughness) | `uRough` | 0–1 | **0.17** | 表面粗糙度，越高越霧 |
| Index of refraction | `uIor` | 1–2 | **1.50** | 折射率（一般玻璃約 1.5） |
| Abbe number | `uAbbe` | 8–90 | **20** | 越低色散越強（冕牌玻璃約 58，火石玻璃約 30，這裡刻意調低以加強效果） |
| Internal scattering | `uMilk` | 0–1.5 | **0.04** | 內部散射，越高越乳白 |
| Absorption | `uSigma` | 0–1 | **0.15** | 吸收強度，基底係數 (0.06, 0.09, 0.02) × 值 × 6 |
| Thin-film iridescence | `uFilm` | 0–1 | **0.60** | 薄膜虹彩的混合比例 |
| Lens fringe | `uCA` | 0–1 | **0.04** | 鏡頭色邊（後製） |
| Grain | `uGrain` | 0–1 | **0.18** | 底片顆粒（後製） |

其他固定設定：相機視角 30°、背景板 z = −6.6、色調映射 `NeutralToneMapping`、霧面取樣 8 次（移動時 3 次）、厚度搜尋 18 步加 4 次二分、像素比上限 1.5。

### 5.2 背景板（Canvas 2D）

| 項目 | 設定 |
|---|---|
| 底色 | `#e1e1e4` |
| 格線 | 畫面高度 ÷ 34 為一格，`rgba(18,18,22,0.09)`，線寬 1.5 |
| 字母 | A、T、E、Q，字型 UnifrakturMaguntia（Google Fonts），大小為畫面高度的 0.78 倍，顏色 `#111114`，粗筆畫刻意放在骷髏正後方 |
| 貼圖 | sRGB，啟用 mipmap（霧面模糊會用到），anisotropy 8 |

### 5.3 Blender 版（`frosted_glass_material.py`，Principled BSDF）

| 參數 | 值 | 說明 |
|---|---|---|
| Base Color | (1, 1, 1) | 純白，不上色 |
| Roughness | 0.15 | 霧面程度 |
| IOR | 1.5 | 折射率 |
| Transmission Weight | 1.0 | 完全透光 |
| Dispersion | 0.08 | 色散（Blender 4.2 以上） |
| Subsurface Weight | 0.04 | 微微乳白，半徑 (0.3, 0.3, 0.45) |
| Coat Weight / Roughness | 0.35 / 0.08 | 光滑的透明表層 |
| Thin Film Thickness / IOR | 380 nm / 1.35 | 薄膜虹彩（Blender 4.2 以上） |
| Sheen Weight / Tint | 0.25 / (0.85, 0.8, 1.0) | 淡紫色光暈 |
| Volume Absorption | 顏色 (0.94, 0.92, 1.0)，密度 0.15 | 厚的地方略帶紫 |

Blender 腳本的其他設定：

- **算圖：** Cycles 128 samples，關閉降噪以保留自然顆粒；透射反彈 24 次；色彩管理 AgX（Medium High Contrast）。
- **合成器：** Lens Distortion 的 Dispersion 設 0.02，產生鏡頭色邊。
- **攝影棚：** 灰色背景（0.75），加上主光、紫色輪廓光、冷色補光三盞面光源。
- **背景板：** 灰色板加上大字 `ATEQ`。要用哥德字體，請在 `BACKDROP_FONT` 填入字型檔路徑。
- **開關：** `SETUP_RENDER`、`SETUP_STUDIO`、`SETUP_BACKDROP` 可以分別關閉。
- **注意：** 這個腳本還沒在 Blender 裡實際執行過，只做過 Python 語法檢查。
